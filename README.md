# R&E Installaties – widgets & automatisering

Code voor maatwerk-onderdelen op [re-installaties.nl](https://www.re-installaties.nl) (Webflow), geladen via jsDelivr en gekoppeld aan n8n.

| Map | Wat | Webflow-pagina |
|---|---|---|
| [`advies-verduurzaming/`](advies-verduurzaming/) | Adviesformulier met 6 stappen (warmtepomp/airco) met rapportmail, leadmail en Google Sheet via n8n | Diensten › Advies verduurzaming |

Elke widget heeft een eigen README met de embed-code. Releases taggen we per widget, bijvoorbeeld `advies-v1.0.0`, zodat de jsDelivr-URL per versie vastligt:

```
https://cdn.jsdelivr.net/gh/flitsdigital/re-installaties@advies-v1.0.0/advies-verduurzaming/dist/re-advies.min.js
```
